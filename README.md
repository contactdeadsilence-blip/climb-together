# CLIMB TOGETHER — DEAD SILENCE Studios
Co-op low-poly 3D climbing game. 1–4 players (Solo/Duo/Trio/Quads) roped together climb a giant mountain.

- `npm install && npm run build && npm start` → http://localhost:3000 (dev: `npm start` + `npm run dev`)
- Render: Node web service, build `npm install && npm run build`, start `npm start`.

Controls: WASD move, mouse look, hold LMB/RMB (or Q/E) to grab, SPACE jump; on a wall tap SPACE to leap (dyno), hold to charge a bigger leap. 1–4 emotes. Gamepad: sticks, LT/RT grab, A jump/leap.
